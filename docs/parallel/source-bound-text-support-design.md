## Purpose and boundary

A new private ephemeral helper owns actual dataset admission, original-text Gold binding, supplied-ranking original-source binding and declared geometry calculation for ONE named case/ONE supplied ordered ranking. It returns source-checked geometric requirement support, not query execution, semantic entailment, human-authored/held-out quality, authorization, answer quality or qualification. No model, network, PDF, vision, new scoring formula, aggregate, stage comparison, generic-ID MRR/nDCG, service endpoint, persistent report or source mutation. Gold/ranking stores are borrowed. No caller-created binding/result DTO or fingerprint may replace any owned call.

The caller is an operator in an authorized private evaluation environment. This helper grants no store/data access and performs no current principal check. Its output and dataset are private/linkable; do not expose them in a serving flow. The existing human requirement for current rights before model exposure remains unchanged. This operator-only composition MUST NOT be called a rights-safe evaluation route. A later current-policy admission boundary must precede any actual data/model use or public score route.

## Owned sequence, joins and clocks

Start one monotonic deadline at public entry before validation. Check before and after each potentially material operation and final result constructor. Every nested public call gets floor remaining milliseconds, capped at its actual public maximum; refuse remaining<1, no fresh timeout. Check after nested return even if it overran. Cooperative only, no hard end-to-end timeout; nested parsing/load/sort/allocation may overrun. No retries/cache across invocation, no catch-and-score fallback.

1. text_evaluation_dataset.admit EXACT original bytes. Select exact case or refuse before store calls; retain actual dataset/split IDs and hash original bytes. No serialization/reconstruction/subsetting changing dataset identity.
2. text_evaluation_gold_binding.bind with EXACT same dataset_bytes and exact sorted gold_bundle_ids. This existing API validates ALL dataset atoms, not only selected case. Preserve that explicit cost and behavior. It performs its own dataset admission/two source observations. All four existing suppliers' caps and refusal behavior remain unchanged.
3. Confirm returned dataset_id/split_id/dataset_sha256/case_count equal owned admission; bind each selected case atom to actual returned GoldBinding by six fields (revision,extraction,block,start,end,text_sha256). Build a bounded six-field lookup from <=4096 distinct global bindings, refuse duplicates/missing/unexpected keys/count mismatch against the parsed dataset-wide distinct set. Count occurrences separately from distinct atoms; do not attach a dataset-wide binding to a case by position. A GoldBinding must have at least one bundle witness, already enforced by actual Gold binder; output DTO itself remains forgeable.
4. source_bound_ranking.bind with same borrowed stores and supplied store_root/snapshot/catalog/chunk_ids/grants/restrictions and remaining original deadline. It owns two actual catalog loads and two selected-source validation passes. Confirm returned snapshot/catalog, row_count and ordered row.chunk_id values equal requests; do not accept a separately supplied BoundRanking. Actual lower binder owns source/Registry/scope/span/hash checks. No Gold membership in snapshot or authority is established by this call.
5. Emit geometry tuple in exact supplied rank order: `(chunk_id,row.revision_id,row.extraction_id,((fragment.block_id,fragment.start,fragment.end),...))` for actual BoundRow/BoundFragment, omitting nothing and inventing no separator interval. Existing ranking binder has already omitted separators. Enforce <=256fragments/row, <=65536total before geometry construction; reject rather than truncate. No copied text or token offsets; half-open original Unicode codepoints. Validate counted total against actual binding.fragment_count. These bounds are not realistic workload qualification.
6. declared_span_support.score_case EXACT same dataset_bytes/case_id/geometry/cutoffs, original remaining deadline. Preserve its current AND atoms / OR alternatives / requirements denominator and keyed (revision,extraction,block) interval union, including overlap/adjacency. Verify resulting dataset/split/case/rank/requirement counts correspond to owned inputs. Retain its fingerprint and at_k records without relabeling nested DTO markers. No requirement grade weighting, partial-atom credit or ID-to-MRR conversion.
7. Assemble bounded private result/preimage, hash with original clock, construct frozen result then check deadline before return. No output persistence. Release local dataset/Gold/row/geometry references when no longer needed; no promise of memory erasure or strict peak RSS. Never append source/question text to logs/report/DTO/preimage.

Ordering is deliberately sequential, not a combined atomic lease or policy epoch. Gold two observations and ranking two observations do not establish a jointly stable snapshot/source/rights transaction or prevent ABA. This is reported explicitly, not silently accepted as current-source attestation.

## Denominators and edge decisions

For each cutoff keep the existing fraction (# fully covered requirements)/(# ALL declared requirements of this case), and complete_requirements means all declared requirements covered. Atom conjunction and alternative disjunction unchanged; grades do not weight this geometric diagnostic. One source atom split across multiple distinct ranked chunks can be covered by interval union. Duplicate chunk IDs refuse; overlap, adjacency and repeated source fragments add no extra credit. Alternative witnesses do not multiply credit. Never call this generic-ID relevance/nDCG or human recall.

Missing/unloadable/invalid/hash-mismatching Gold or unsupported PDF/visual Gold refuses whole call with no numeric score. Never filter it away or turn unavailable data into zero. Dataset-wide unrelated invalid Gold also refuses because actual Gold binding is dataset-wide; callers must supply an intentionally scoped dataset before invoking, not an internal hidden subset.

Valid bound Gold outside selected snapshot or denied by supplied rank grants stays in the declared denominator, with explicit Gold eligibility NOT_CHECKED. Absence from ranking naturally yields uncovered geometry. This is a source-span support diagnostic for a declared target, NOT authorized-corpus recall; it cannot distinguish out-of-snapshot, scope denied, unretrieved or semantically inappropriate target. A later authorized benchmark must decide eligibility BEFORE freezing dataset/denominator and independently audit it. Unauthorized/unknown selected ranked rows are refused by actual ranking binder, not removed. This avoids silent denominator changes without claiming Gold rights.

Positive-Gold case + empty ranking: ranking binder still validates both catalogs but no selected source; support fractions0, completeFalse, selected source status NO_SELECTED_SOURCE_VALIDATED. No-Gold case (unanswerable OR unknown per parser): fractions/completeNone with NO_GOLD_REQUIREMENTS, distinguish answerability label; neither empty nor nonempty ranking proves successful abstention. If another dataset case has Gold, global binding status may validate sources while selected-case status is NO_CASE_GOLD_REQUIREMENTS; report both. All-no-Gold dataset requires no Gold bundles per existing binder; validates no Gold source. No aggregate/denominator averaging in v1.
