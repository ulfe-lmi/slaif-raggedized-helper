# Raw snapshot source membership

`parse` checks canonical historical declarations. `build` reloads caller-selected actual ingestion bundles against their originals, including selected sources with zero rows. `bind` checks declared core and row-map correspondence; `validate` binds and freshly rebuilds exact bytes. Stores are borrowed. Errors expose no source content.

Selection is not proof of external inventory completeness, current rights, or withdrawal authority. This component does not prove vector or neural execution, publication, a full loader, CAS, retention, search, qualification, ICA, or MVP readiness. A fresh affected peer review and current canonical integration and CI remain necessary. The strongest counterargument is that selected historical bundles cannot demonstrate that omitted external sources or withdrawals were accounted for.
