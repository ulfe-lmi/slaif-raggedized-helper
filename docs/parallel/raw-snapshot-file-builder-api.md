# Raw snapshot file builder

`build(originals, derived, row_map_bytes, active_bundle_ids, withdrawn_revisions, query_context_bytes, *, deadline_ms=30000)` returns frozen core and sorted file bytes for an explicit selection. Inputs are canonical bytes and sorted immutable identity tuples; stores are borrowed. Query context is canonical ASCII JSON with schema 1, kind `slaif-raw-snapshot-query-context-v1`, space and definition identities, declared query policy and execution fingerprints, and a null or prefixed precision qualification reference.

The builder constructs actual source membership and partition payloads, then parses the core and validates the complete files against fresh sources. The candidate DATA `passed` marker identifies a software validation policy; it is not authorization, current rights, model compatibility or readiness. The result always states `SUPPLIED_UNVERIFIED` and `NOT_QUALIFIED`, even with a declared qualification reference. Selection is explicit and does not prove corpus coverage. Retention, purging, current policy and rights, serving readiness, model and hardware qualification remain separate obligations. Publication and selection are separate caller actions. The deadline is cooperative, not hard preemption.
