# Supplied ranking source binding

`bind(originals, derived, store_root, snapshot_id, expected_catalog_id, chunk_ids, *, grants, restrictions=None, deadline_ms=30000)` binds an exact tuple of up to 4096 distinct chunk IDs in supplied order. It borrows the existing original and derived stores; `store_root` is a canonical absolute snapshot directory. Both snapshot and expected catalog identifiers are required. Grants and optional restrictions are copied before source validation. A selected row denied by those supplied grants causes a content-free `SourceBindingError` for the whole call.

A nonempty `BoundRanking` contains `BoundRow` records in the supplied order. Each row carries its catalog ordinal, source and representation identities, a hash of its actual canonical scope, and a tuple of `BoundFragment` records. Fragment offsets are half-open Unicode codepoint intervals in original blocks; their hashes cover the exact copied UTF-8 text. Separators and generated rendering are not source intervals. The result does not contain source plaintext, rendered text, scores, or tokens. It is private linkable data, not anonymized data; callers are responsible for protecting it.

The result marks its origin `SUPPLIED_RANKING_UNVERIFIED`, authorization `SUPPLIED_SCOPE_CHECKS_ONLY`, execution `NOT_ATTESTED`, and qualification `NOT_QUALIFIED`. An empty tuple still triggers two complete catalog validations and reports `NO_SELECTED_SOURCE_VALIDATED`; this does not prove a retrieval was empty or an abstention correct. Constructors are ordinary forgeable DTOs and are not later admission credentials.

For each pass, selected bundles are revalidated from the borrowed stores, with cumulative limits of 128 bundles, 4096 block occurrences, 100663296 metadata and member bytes, 65536 source fragment occurrences, 16777216 copied UTF-8 bytes, and 2097152 block-ID UTF-8 bytes. Repeated occurrences count repeatedly. The loader may allocate before cumulative refusal; these limits do not establish a peak-memory bound. The deadline is cooperative, starts before admission, and is checked after constructing the result; nested loaders retain their own clocks.

The two observations do not prove current rights, prevent ABA, establish a lease, qualify PDF or visual extraction, or guarantee a hard deadline. Actual query provenance, rights, held-out quality, licenses, security, full integration review and release remain separate gates.
