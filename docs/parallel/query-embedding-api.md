# Private resident query encoder

`ResidentQueryEncoder(manifest_bytes, artifact_root, definition, tokenizer_definition, expected_inventory_id, tokenizer_runtime, cpu_runtime, *, worker_policy=None, parent=None)` owns one `IsolatedCPUEmbeddingSession`. Enter it once with `with`; call `encode_query(text)` for each query. Admission, staging, independent native tokenizer, CPU worker, finite policies and cleanup are inherited from that session. No downloads or process-global cache are added. The CPU worker is reused; its finite lifetime and call limits still apply, and the native worker may renew. An actual session error refuses the instance; malformed raw input does not consume it. Calls, entry and close refuse concurrent use and reuse after fork. Close may be retried for pending cleanup; `cleanup_owner` retains the actual session, including its pending handles, independently of any exception attributes. Interruption identity is preserved by the owned session without relying on exception annotations; cleanup interruption takes priority over an ordinary error. Ordinary refusals contain no query or path.

Query policy v1 is the SHA-256 of the canonical ASCII JSON record in `_POLICY`. It accepts exactly a built-in nonblank Unicode string of at most 8192 characters and 32768 UTF-8 bytes, strictly encoded. It passes the original string unchanged with no prefix, title, normalization, truncation or padding. The admitted definition must have `query_prefix=None`, CLS pooling, L2 normalization and 1024 dimensions. The independent native 0.21.4 tokenizer enforces the 1024 ID limit including special tokens before CPU forward.

The frozen `QueryEmbedding` contains immutable 4096-byte little-endian FP32 normalized payload, its SHA-256, admitted space and definition identities, intended CPU FP32 fingerprint, actual observed execution record and fingerprint, and query policy ID. It contains neither query nor token IDs. The encoder validates one row, payload/row consistency, digest, finite norm, identities, receipt, observed record and runtime state; it does not renormalize the result. `QueryRefused` is the ordinary input-free refusal. An inherited session owns actual handles even on refusal; retain the encoder and call `close()` again if necessary.

This is a private embedding primitive, not authentication, current-policy enforcement, scoped retrieval, corpus access, snapshot compatibility, or authorization to expose a model to content.
