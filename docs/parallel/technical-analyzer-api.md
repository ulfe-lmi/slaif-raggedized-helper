# Technical analyzer candidate

`analyze(text: str, policy: Policy = Policy()) -> Analysis` returns an immutable ordered tuple of `Term(text, start, end, derivation)` and `analyzer_id`. `analyzer_id(policy)` uses the existing canonical fingerprint over version 1, all limits, NFKC/casefold policy and Python Unicode database version. Compatibility requires identical identity. Exact strings only; lone surrogates are refused. The analyzer does not access sources or authorize callers; terms are sensitive derived source artifacts and must not become routine telemetry.

Spans are half-open Unicode codepoint offsets in the exact input. Literal terms preserve case, punctuation and duplicates in source order; terminal dots and colons become separate literals. Runs comprise Unicode word characters, combining marks U+0300–036F and `./\\:+%=-`; other non-whitespace characters are individual literal unknowns. Each run is followed by its NFKC then casefold alias when changed, and by alphanumeric/mark components split at connectors, with their own aliases when changed. Derived terms point to the precise supporting span; their text need not equal that slice. Empty or whitespace-only text yields no terms. This is a bounded lexical subset, not a language, path or URL parser; no fetch or execution occurs. No stemming or stopword removal occurs. Case-sensitive originals remain available. Never use these aliases to merge question, cache, or source identities.

Policy has positive strict integer limits, with fixed ceilings: bytes 4,000,000; codepoints 1,000,000; token characters 16,384; emitted terms 500,000; components per run 1,024; cumulative work 10,000,000; deadline 60,000 ms. Defaults are lower. Work counts scanned run characters and emitted term characters plus per-operation units. The monotonic deadline is checked during analysis; it is a refusal threshold, not a performance guarantee. Overflow, invalid policy or invalid input raises `AnalyzerError('analysis refused')`, never a partial result or input-bearing error.

This is only a term source. Real bm25s adapter, serialization validation, row mappings, access partition selection, fusion, immutable snapshots and held-out quality evaluation remain future gates. It does not qualify a model or retrieval quality.
