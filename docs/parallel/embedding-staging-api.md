# Embedding staging

`stage(manifest_bytes, artifact_root, definition, tokenizer_definition, expected_inventory_id, *, parent=None, timeout=120)` yields a frozen `Staged(path, manifest_bytes, space)` within a context. Keep the context open through backend loading. The public record is forgeable, not independent evidence. The source is admitted, each declared file copied and checked, and the private copy admitted again; this costs three full reads. Deadlines are cooperative and cannot interrupt a blocked filesystem call. The optional parent must be owned and private; its ancestry and filesystem must be trusted. Files are read-only and directories private during use, but a same-UID or privileged writer can change them. Cleanup removes the owned temporary tree on exit or failure. This proves matching bytes, not publisher, license, durability, or model readiness.
