## Exact metrics

For each of three returned variants and cutoffs20/60, retain each case's integer covered/required revision counts or its explicit source-undefined reason, and meaningful complete-evidence Boolean or NO_GOLD_REQUIREMENTS. Source macro is arithmetic mean of per-case covered/required fractions over defined cases, including defined zeros. Complete-evidence rate is mean of meaningful Booleans, including false; OR alternatives are meaningful here even when source recall is undefined. These two denominators differ. Every aggregate records total case count, defined, undefined, reason counts and denominator. No defined values means None with explicit reason, not zero. Micro pooled revision recall is NOT the macro; no need to implement a second recall metric merely because the oracle demonstrates their difference.

For each of seven existing removal transitions:

- Complete-evidence loss numerator is cases true before and false after; denominator is meaningful cases true before. Record meaningful-defined, undefined, eligible-complete-before and defined-incomplete-before counts. Zero eligible means None/NO_ELIGIBLE_COMPLETED.
- Source loss is mean of before-minus-after source recall over cases defined at both endpoints. Keep explicit defined/undefined/reason counts. Zero defined means None/NO_DEFINED_SOURCE. Changing universe/undefined status or gains refuse.
- Requirement and alternative loss each record raw lost count, raw before-covered count, eligible case count (before-covered>0), undefined case count, pooled lost/before and macro mean of per-case lost/before over eligible cases. These are distinct named values. Zero eligible means both values None/NO_ELIGIBLE_BEFORE. Do not substitute total declared requirements for before-covered counts.

Input geometry provides all necessary coverage/transition fields; do not run the geometry scorer again to aggregate them. Report per-case bounded numeric prefix and loss summaries with case ID and supplied geometry ID for error analysis, plus six aggregate prefix summaries and seven aggregate transition summaries. Never emit raw atoms, requirement/alternative/revision IDs, hit/trace objects, source text, vectors, questions, paths or exception details. Case/geometry IDs remain PRIVATE LINKABLE DATA, not anonymization. MRR/nDCG are UNAVAILABLE with existing NO_EXPLICIT_CHUNK_RELEVANCE_MAPPING; requirement grades never become chunk grades. Downstream rerank/packing stages are unavailable/not observed.
