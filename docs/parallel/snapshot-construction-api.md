# Private selected DATA construction

`build_publish_select_data` joins the completion locator to fresh source-backed program coverage, the file builder, immutable publication and expected-pointer selection. It borrows both stores. The completion DTO is supplied structural data, not proof of execution. Successful results are `SELECTED_DATA`, `SUPPLIED_UNVERIFIED`, and `NOT_QUALIFIED`; they do not establish current rights, serving readiness, model precision or quality.

The outer cooperative deadline is checked around each stage and after result construction. It cannot preempt nested work: coverage and file builder start nested budgets, file validation uses its own fixed budget, and publication has no configurable deadline. The outer duration is not a hard wall limit. Coverage and file builder retain their existing row, group and byte bounds.

A content-free `ConstructionError` exposes the stage, known candidate ID and publication/selection attempted flags. A flag is set before the corresponding side-effect call. An exception or deadline after either attempt leaves durable state uncertain; callers must independently reconcile it. The function does not retry, delete, restore a pointer or close borrowed stores. Current authorization, query encoding, capacity, licensing, quality and hardware qualification remain separate gates.

Unit fixtures exercise only typed mock boundaries. The source-backed journey requires a separately approved finite proof plan; collection alone does not establish actual store behavior.
