# Private source-bound stage diagnostics

`bind_stages` accepts a full dataset, selected case, borrowed active pin, supplied hybrid
trace, query vector and explicit authority. It observes source bindings sequentially and
passes the complete eligible ranking and ten stage relations to the pure geometry
component. It does not run search, an encoder, BM25 scoring or a fusion service. Dense
and lexical score order remains `SUPPLIED_SCORE_ORDER_NOT_REEXECUTED`; the pure
component retains `UNVERIFIED` source binding. These observations do not establish
current rights or atomicity.

The owned logical work and cumulative payload limits are 134,217,728 and 268,435,456.
They are not CPU, memory or physical I/O limits. The fixed source envelope includes five
direct pin checks, one direct catalog load and two catalog loads inside ranking (three
catalog loads total), one Gold binding and one ranking binding. Its maximum is 12,288
derived loads and 4,986,555,627,809 logical read-payload bytes. The pure component's
29-pass work and serialization ledger is reserved separately after source bindings reveal
its operands. Final totals are observed after the identity checkpoint and are not included
in their own invocation hash.

Controlled unit data is not actual source attestation. The final focused controlled unit
run passed 51 tests and Ruff7 passed on the same Python bytes. Earlier pytest1 reported
11 passes and 10 failures during synthetic row-map setup; pytest2 reported 46 passes and
one failure from a no-Gold fixture that retained an unrelated case's Gold. Those failures
and their corrections remain preserved. Root's renewed checkpoint review is pending.

A separate bounded source-backed producer-trace-to-geometry proof remains necessary.
Held-out quality, current rights, model execution, scale, visual support, licenses,
independent code audit and MVP acceptance remain unqualified. Conventional chunk MRR
and nDCG are unavailable without explicit chunk relevance; declared source recall remains
unqualified and is undefined for alternative source universes and no-Gold cases.

The strongest objection is that even a successful binding establishes only sequential
consistency of supplied traces with observed source metadata. It cannot prove that the
supplied ranking was produced by the declared model or scorer, that a policy remains
current after the last observation, or that the diagnostic predicts user quality. A
controlled fixture is not evidence of an actual source-backed producer journey.

Root's review of the first implementation checkpoint required a declaration-encoding
accounting fix and additional controlled tests. The earlier 47-test pass predates those
changes; the later 51-test pass covers them. Ruff6 initially found one unused fixture
variable, corrected before Ruff7. The existing old-pin test checks that the wrapper does
not consult current selection; it does not establish behavior after an actual
selection-generation advance.
