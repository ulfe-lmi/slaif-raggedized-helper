# Raw hybrid DATA composition

`raw_hybrid_search.search(originals, derived, store_root, snapshot_id, text, query_payload, *, query_space_id, query_definition_fingerprint, query_policy_id, query_execution_fingerprint, grants, restrictions=None, dense_k=60, lexical_k=60, partition_cap=60, k=60, deadline_ms=120000)` borrows the two stores. It executes actual dense, lexical and reciprocal-rank fusion in sequence on the explicit snapshot. Each stage receives the independently captured static authority and the remaining portion of one cooperative deadline; this is not hard preemption. Any failure refuses the entire request with content-free `HybridSearchError`; non-Exception interruptions propagate.

The exact root must be normalized absolute UTF-8, at most 4096 bytes, without control characters or empty, dot or dot-dot components. Snapshot is `sha256:` plus 64 lowercase hex digits. Text is exact UTF-8, at most 8192 code points and 32768 bytes. Payload is exactly 4096 bytes of finite normalized 1024-dimensional little-endian float32, within 1e-4 norm tolerance. Space, policy and execution IDs are bare 64 lowercase hex digits; definition is `sha256:` prefixed. Caps are exact integers from 1 through 60, deadline is an exact integer from 1 through 120000 ms. Grants are required; empty grants deny all. Authority fields follow the existing bounded Grants/Restrictions admission. Pinned cached NumPy 2.5.4, bm25s 0.2.14 and SciPy 1.18.1 are required even for empty success.

The frozen `HybridResult` contains snapshot_id, catalog_id, query_id, query_text_sha256, query_payload_sha256, authority_sha256, query_origin, qualification and the full actual dense, lexical and fusion results. Their hits, raw scores, ranks, partition counts, caps and fusion counts remain available. Final hits are `fusion.hits`. Canonical UTF-8 JSON with sorted keys and compact separators binds kind `raw-hybrid-query/v1`, snapshot_id, catalog_id, both query hashes, all four declared encoder IDs, authority_sha256 and the four cap values. The authority hash covers canonical JSON `[grants, restrictions]` using the same serialization.

The labels SUPPLIED_UNVERIFIED and NOT_QUALIFIED are deliberate: correlation does not prove the vector encodes the text, declared encoder execution, precision equivalence, a qualified pair, current authorization or held-out quality. The strongest objection is that these inputs and static authority remain caller-supplied and the cached dependencies have not established deployment readiness. Catalog reads are consistency observations, not retention or future policy guarantees. Private integrity validation may inspect denied source data; denied rows do not enter scoring, lexical statistics, fusion, output or model dispatch.

The wrapper loads the complete catalog before the engines and again after fusion; each constituent also performs its own initial and final catalog validation. A successful journey therefore performs eight catalog loads. Existing catalog limits remain 4096 rows, 128 partitions, 16 MiB of vectors and 32 MiB of nonvector data; engine scorer and candidate bounds remain in force. These are finite software limits, not a 20,000-row qualification. Dense and lexical global ranks are converted directly into COMPLETE fusion entries; their source ordinal and partition, chunk, revision and representation identities remain unchanged. The fusion result retains input row counts, candidate and overlap counts, returned count and global cap flag; constituent results retain their own eligible, matching, selected and returned counts and cap flags.

Verification used a tiny synthetic three-row, two-scope published snapshot and actual dense dot products, rendered-term BM25 and RRF. Focused cases exercised caps, authority mutation, source changes, deadline refusal and a different-query lexical handoff: an isolated text-hash guard control admitted the actual mismatched ranking, while the restored guard refused it and the restored healthy baseline passed. An initial cap-test expectation failed because the lexical cap remained 3; the failure was retained and a corrected case passed. Stable tie behavior is inherited from the unchanged, previously reviewed constituents; the wrapper cap oracle did not separately assert a tie. This evidence does not establish full runtime, quality or serving qualification.

## Same-call stage traces

The keyword-only `trace` defaults to `False` and accepts only an exact boolean. It is forwarded to the one dense and one lexical search used for fusion. When false, both nested trace values must be `None`; when true, private lower traces are admitted and linked to the actual results, request, counts and returned identities before fusion. Their existing trace IDs and schemas are checked; the hybrid query ID and `HybridResult` fields do not change. Successful runs with unchanged observations retain the previous non-trace fields and rankings. The lower dataclasses now add nested `trace: null` under `dataclasses.asdict` even in the default case, so pre-trace serialization is not byte-compatible.

Admission bounds rows to 4096, partitions to 128, strings to 128 characters, each ordinal sequence to 4096, returned sequences to the modality k (at most 60), and cumulative ordinal items to 16504 before structural validation and hashing. Each existing canonical trace preimage has a 4 MiB encoded-work limit. The original cooperative deadline includes validation, hashing, fusion, fresh catalog and result construction; an overrun refuses the whole result. The trace and nested results contain private source and rank DATA, including supplied vectors and static grants. They do not establish a current principal, neural execution, rights attestation or qualification and must not be exposed as public telemetry.

The new trace adapter's unit tests use synthetic DTOs and independent literal encoding vectors; they do not establish actual scoring or authorization. A separately approved owned synthetic proof exercised actual false/true engine calls, denied poison exclusion, source chunk correspondence and a valid-hash inconsistent trace: the restored link guard refused, while withdrawal of that guard allowed the controlled result. A second case confirmed partition cap loss with selected=returned=1 and no global cap loss. These cases do not establish current rights or model execution. Whole 008 and 009, raw-query neural execution, current policy, Gold eligibility, 20k scale, license audit, quality and full text and visual MVP remain partial or unproven.
