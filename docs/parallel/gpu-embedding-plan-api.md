# GPU embedding plan

`gpu_embedding_plan.build` independently admits and counts original source, checks a borrowed
prepared launch and returns an immutable plan and actual journal specification. The caller owns
and closes the original store, launch and reservation. The execution dependency is the bare
SHA-256 of the validated complete predicted record; the intended GPU identity remains distinct.

This predicts software correspondence, not observed execution, current rights, actual model or GPU,
FP16 or parity, durable completion, security, licensing, ICA or MVP qualification. No device or
model starts here. A later producer must obtain current authorization, revalidate and compare actual
execution, and enforce live dispatch budgets before exposure.
