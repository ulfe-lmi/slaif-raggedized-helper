# Private source-bound text support

`source_bound_text_support.score_case` accepts borrowed original and derived stores, a trusted snapshot directory and catalog identity, original dataset bytes, a case ID, sorted Gold bundle IDs, ordered chunk IDs and supplied ranking grants. It returns a frozen `TextSupport` containing declared requirement coverage at the requested cutoffs. All declared requirements stay in the denominator. Missing or inconsistent inputs are refused with a content-free `TextSupportError`; an empty ranking is distinct from a case with no Gold requirements.

The wrapper admits the complete dataset, binds Gold across the complete dataset, binds the supplied ranking to its source, then applies declared span geometry. Dataset-wide Gold binding can refuse because of an unrelated case and incurs the supplier's full cost. Calls share one cooperative deadline; this is not a hard runtime or memory limit. Sources are observed sequentially, not under an atomic lease.

This is an operator-only private diagnostic. Result IDs are linkable; do not publish result data or use it as a serving route. Gold eligibility and current Gold rights are not checked. Supplied ranking, query execution, human quality, held-out status and model or hardware qualification are not attested. Current rights must be checked before actual data or model exposure. No plaintext, question text, path or source fragments are retained in the result.

The frozen design and synthetic oracle are adjacent files. The three prerequisite modules are exact source blobs identified by the input pins and the order. The concrete vector tests use actual dataset admission and geometry with controlled Gold/ranking outputs, and do not constitute source-store or authorization proof. Actual-store composition requires the separate planned proof and Root decision described in the order. Current-head CI and independent rights and quality gates remain future work.
