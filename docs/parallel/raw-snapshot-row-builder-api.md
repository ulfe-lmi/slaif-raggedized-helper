# Selected batch row-map construction

`build(originals, derived, declaration_bytes, groups, *, deadline_ms=30000)` reads borrowed typed stores and constructs canonical v1 row-map DATA for explicitly selected whole batches. The declaration is canonical ASCII JSON with schema 1, kind `slaif-raw-row-map-build-declaration-v1`, and the five existing row-map header fields. Groups are a sorted tuple of unique `(bundle_id, batch_id)` bare SHA256 pairs, with no repeated batch ID. The definition header uses `sha256:` while the batch dependency is bare, as specified by the existing source-row contract. The supported representation and normalization policies are the existing raw policies.

Each batch is freshly validated and every row is bound to its actual bundle and stored batch position; a second fresh source-row validation checks each complete group. Duplicates and inconsistent inputs refuse rather than select a winner. The result contains map bytes and hash, row and group counts, `SUPPLIED_UNVERIFIED` execution origin and `NOT_QUALIFIED` qualification. Empty groups produce empty DATA without reading stores. Limits are 128 groups and partitions, 4096 rows and 16 MiB map bytes, subject to inherited source and batch limits. The deadline is cooperative and includes final result construction.

Selected batches do not prove whole-corpus coverage, actual neural execution or tokenization, present rights, authorization, readiness, or hardware qualification. Current-policy authorization and a complete source-program cut are separate obligations. The builder does not publish or select a snapshot and does not close borrowed stores.
