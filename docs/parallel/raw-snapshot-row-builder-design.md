## Product step and exclusions

Add one bounded product constructor `raw_snapshot_row_builder.build(originals, derived, declaration_bytes, groups, *, deadline_ms=30000)`. It constructs a canonical existing v1 raw row map from actual stored ingestion bundles and whole stored embedding batches. It replaces the need for a caller to manufacture per-row correspondence metadata. It is a prerequisite for a separate core/payload assembler, publisher and current-policy reader composition, not a complete snapshot or serving interface.

Only NEW module, unit/composition tests, API and exact Root design/order. Existing codecs/source/store/producer/executor/fixtures/CI/pins/law remain unchanged. No publication, output files, model/tokenizer/framework invocation, network/install, current pointer, source deletion, authorization provider, service or global mode change. Store reads validate configured private data; they do not expose rows to a query principal or grant current rights. Preserve source originals and all existing container/hash domains.

## Inputs and declared identity

Borrow exact OriginalStore and derived_store.Store; never close them. `groups` is an exact builtin tuple of exact `(bundle_container_id, batch_container_id)` tuples, each two exact bare64 lowercase SHA256 strings. Require lexically sorted unique pairs, no repeated batch ID, at most128 pairs. These are explicit selected whole batches, not a promise that the entire corpus or source program was indexed. No partial per-batch row selection, silently dropped bad row, implicit dedup/latest choice or arbitrary regrouping.

`declaration_bytes` is exact immutable ASCII canonical JSON, 1..4096 bytes, no duplicate keys, extra fields, floats/constants, bool schema or subclasses:

- schema=1, kind=`slaif-raw-row-map-build-declaration-v1`;
- space_id, representation_policy_fingerprint, chunk_policy_fingerprint as bare64;
- definition_fingerprint as exact `sha256:`+64;
- normalization_policy_id exactly embedding_vectors.POLICY_ID.

This is DECLARED context, checked against every actual nonempty input. It never proves neural execution, query/corpus compatibility or qualification. The known raw representation policy is the existing rr.Policy/BatchPolicy fingerprint; reject unsupported policy even for empty groups. A prefixed definition ID corresponds to the specifically defined bare batch dependency by the existing source_rows contract; do not strip/add prefixes to pretend unrelated query, intended execution or full observed record hashes are equivalent.

Cheap exact type/path-independent ID/declaration/deadline admission and independent builtin input capture precede store load. Deadline strict int1..120000, no bool; one original monotonic cooperative budget from before admission through final validation and return. Check before/after each fallible store/source call and before success, including final operations. Compute the final map hash and bounded result object before the last deadline check; no expensive hashing/validation remains after it. No reset of budget or hard-preemption claim. Existing inner loaders retain their own bounds. Ordinary failures are content-free; original non-Exception identity/known pending resource associations survive, no hostile formatting/attribute dependence. No background work or destructor cleanup.

## Construction and actual-source proof

1. Construct the empty existing row-map header from exact captured declared fields and admit through raw_snapshot_rows.parse, using its unchanged canonical schema/bounds. This is actual empty DATA, never a placeholder presented as source proof.
2. For each captured pair, freshly ingestion_store.load the bundle through actual originals/derived stores. Freshly load the actual batch container, derive its canonical stored metadata from the validated manifest using established derived-store encoding, and embedding_batch_store.load it. No caller LoadedBatch/Registry/RowMap/parsed DTO success substitutes. Retain only bounded metadata/row records needed for construction; do not retain every matrix or bound source group/text buffer across groups. Verify then release per-group temporaries. No aggregate memory qualification is inferred from structural bounds.
3. Validate declared space/definition/normalization/representation policy against strict actual batch dependencies; validate actual bundle tokenizer-definition binding through the same source contracts. Every batch row must belong to that actual bundle: exact original chunk/revision/extraction and chunk-policy ID. The actual batch is1..128rows. Derive the scope partition fingerprint from the actual admitted bundle scope `(schema=1,corpus,version,labels)` and source-scope fingerprint using the existing formula. No caller ACL label or row partition accepted as authority.
4. Construct each row by copying the eight strict actual batch row fields, not fabricated hashes/counts: chunk/revision/extraction, representation/rendered/source_scope/input hashes and token_count. Add actual bundle and batch container IDs, SHA256 of each freshly loaded canonical metadata, original batch row index and actual batch dependency execution fingerprint. Preserve original source chunk IDs and separate rendered representation IDs. Tokens/counts remain stored declaration evidence, not a fresh neural/native qualification.
5. Reject global duplicate chunk ID, duplicate representation, duplicate `(batch ID,batch row)`, mixed declared definition/policy/norm, wrong bundle or changed chunk policy. Keep at most4096total rows/128groups/128partitions and unchanged16MiB row-map byte limit; reject excess before unbounded accumulation. Never drop/reorder batch vectors or silently select a winner. Sort output rows by existing `(partition_id,chunk_id,representation_id)`, assign contiguous global ordinal and independent partition_row. batch_row remains its original stored position after sorting.
6. Serialize canonical ASCII existing `slaif-raw-row-map-v1` and admit it through actual raw_snapshot_rows.parse. Then call actual raw_snapshot_source_rows.load_group for EVERY group against this constructed map, with fresh source/store validation and all existing full metadata/text/rendered/input/representation/vector/row-index correspondence checks. Require each bound group covers exactly that whole batch's declared rows; no extras or omissions. Persisted metadata hashes bind observations across early construction and final verification. Do not replace downstream validation with matching labels or caller data.
7. Before success check original deadline again. Return frozen bounded `BuiltRowMap` containing canonical map bytes and map SHA, row/group counts and fixed execution_origin=SUPPLIED_UNVERIFIED, qualification=NOT_QUALIFIED. Actual full source validation is an observed DATA property, never current-reader authorization. For groups=(), rows=(), counts0 and no sources validated; retain declared header and explicit empty status. A closed borrowed store need not be accessed to construct an empty declaration; never label that as a successful store or source qualification.

No 20k-capacity claim: current4096-row/128-group/byte bounds remain, and source-program completion/corpus membership coverage is a separate assembler obligation. A source bundle may contain additional chunks not in explicitly selected groups; this API does not say those were indexed. A later full-corpus assembler must prove its own selected-program/batch cut set and active/withdrawn membership.

## Proof design

Cheap units: canonical declaration/types/order/duplicates/subclasses/deadline/bounds refused before actual load, deterministic empty map/status, field-domain separation and no write/close/dispatch. Avoid negative tests that always fail on an unrelated invalid default. Unit module must run PYTHONPATH=assignedsrc only; no integration fixture import/path loader.

Three planned actual tiny cases, each own CPU30/AS1GiB/wall120 process, five thread variables1/no bytecode/private0700/tmp. Existing actual source_rows fixture with3rows in2stored batches is a suitable independent hand oracle: it deliberately stores original batch order `(1,0)` and a second `(2,)`. Positive builder input uses only actual pair IDs and header, never the premanufactured row map. Require exact byte equality with the independently constructed existing map and successful real group loads/vector row correspondence. Check borrowed stores remain usable and deterministic output.

Second case: actual original corruption/withdrawal or stored batch corruption must refuse construction with no output write; restore only owned fixture data and distinguish refusal from empty-success behavior. Third case: individually valid but overlapping distinct batch containers for the same chunk IDs must refuse globally rather than dedup silently; wrong declared definition/chunk policy also refuses. Keep real typed stores and validators active; no entire build/load/validation oracle substitution. New constructor can rely on inherited validators; a redundant-guard control that still reaches a later independent refusal must be reported precisely, never fabricated as unsafe output.

Default whole integration collection must include new module without module-name collisions or new import-time sys.path mutation. Individual integration fixture commands may explicitly include their documented existing unit/integration paths; that is separate from unit-only proof. Exact cached app/native setup and pre-invocation driver/source/fixture hashes belong in final order. Within the finalized three-case allowance proceed without another Root permission; failed/extra/changed-cost cases preserve raw evidence and require revised Root decision before retry. No broad predecessor replay or cap raise.
