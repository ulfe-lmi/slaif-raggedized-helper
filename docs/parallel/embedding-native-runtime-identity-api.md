# Native runtime identity leaf

`predict(Runtime(root, packages, 'python3.12'))` inspects selected executable, complete
closed tokenizers and distribution trees, fixed embedding policy and four application source
files. It returns a frozen record of detached canonical bytes and a domain-separated SHA-256.
The two bounded scans detect changes at their observation boundaries; transient changes between
boundaries are not ruled out. Package counts and paths are not runtime qualification.

`validate_record(bytes)` checks only the canonical persisted declaration and computes its
fingerprint without filesystem or process access. Neither operation grants authority or proves
that a native runtime loaded or ran. Source and package hashes do not establish ABI, publisher,
license, security, authorization, or semantic identity. Python standard library and system
libraries are excluded. Actual native execution, GPU package bytes and complete bridge,
producer/controller, current rights, precision, quality, independent audit and canonical CI
remain separate gates. Existing CPU records and overall objective 007 are unchanged.

Descriptor cleanup failures are retained in private process-local uncertainty state; exception
notes are best effort and may be unavailable. An attempted
close is never retried because a failed or interrupted close may already have released the number;
this cannot guarantee cleanup after an uncertain operating-system close outcome.
