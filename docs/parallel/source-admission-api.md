# Local original admission candidate

`parse_manifest(bytes)` accepts bounded UTF-8 JSON with schema version 1 and up to 128 sources. Each source requires logical ID, root-relative path, inert display URI, corpus, explicit access labels (empty means public), processing approval, independent redistribution rights, media type, byte size and lowercase SHA-256. Optional descriptive facts default to unknown. Duplicate JSON keys, unknown fields, unapproved processing, unsafe paths and unsupported types fail. The display URI is data, never an access target.

`OriginalStore(path)` creates or opens an operator-controlled private local POSIX directory. `admit(approved_root, source)` opens the approved root and every component without following symlinks, reads bounded regular-file bytes and verifies size, digest, descriptor metadata and directory bindings. It publishes a digest-named blob and a versioned revision record with a canonical fingerprint of all source metadata. `inspect(revision_id)` verifies both record identity and blob checksum. Call `close()` when finished. Sources are originals only; no extraction fingerprint or parser is implied.

The store requires a private directory protected from untrusted local modification and a local filesystem supporting atomic hard links and directory fsync. Staging and immutable publication occur in the destination directory; a pre-existing object is accepted only after exact verification. An interruption can leave a complete blob without a revision; retry is safe. The optional fault callback is a deterministic test seam and must not be used with untrusted code. This is not authentication, access enforcement, revocation, a snapshot, source serving, or legal approval.

A parsed `Source` holds access labels as an immutable tuple. To change labels or other metadata, validate a new source record and admit it as a distinct revision; the API does not attest who authorized a change. Admission revalidates a fresh source snapshot before opening files, including for records produced with Pydantic's unchecked copying facilities. Descriptor traversal independently checks relative components. Read verification compares file identity, size, mode, nanosecond modification and change times, and exact digest; normal access-time updates are ignored.
