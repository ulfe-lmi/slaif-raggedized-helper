# Raw row-map declarations

`parse(bytes)` returns detached frozen declarations; `subset_bytes(map, partition_id)` returns the canonical complete partition subset; `bind(core_bytes, map_bytes)` freshly parses both and checks their declared correspondence. `RowMapError` contains no input details. A successful bind, including a core declaring validation passed, is data only: it grants no readiness, access or publication authority.

The codec verifies neither actual payloads nor source records, rights, deletion coverage, vector normalization, dense or lexical files, or their correspondence. It does not adapt rendered inputs or load a snapshot, publish with a current-generation CAS, retain pinned handles, or establish real-model behavior, precision, quality, security, licensing, independent audit or canonical CI. Corpus execution fingerprints are separate from CPU query execution. The existing LegacyDenseIndex cannot consume this codec without a new source-verified adapter; prefix conversion does not fix the different identity semantics. A future adapter must rederive source-bound representation and batch hashes including title, heading and text. This leaf does not close 007, 008 or MVP.
