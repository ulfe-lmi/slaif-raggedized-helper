# Embedding space admission

`admit` verifies the caller-selected manifest and protected local artifact tree, compares the operator-configured expected inventory ID, and binds the sole verified safetensors weight and tokenizer to the supplied definitions. Version 1 supports BGE-M3 CLS, L2 normalization, 1024 dimensions and identity query preprocessing only; multiple weight shards are unsupported. The caller must supply an absolute, lexically normal root and its exact `tokenizer.json` path; alternate paths and aliases are unsupported. The verifier requires protected files and rejects symlinks.

The resulting identity excludes paths and execution device or dtype. The expected ID is configuration, not approval, a license, or publisher attestation. This verifies synthetic or supplied files, not a loaded model. A future loader must repeat admission at its actual trust boundary and consume only verified files; this API does not ensure framework file selection or prevent changes after verification. It does not establish provenance, licensing, current authorization, hardware qualification, or model behavior.
