## Trust and invariants

The module creates no named staging entry and never invokes unlink/remove/rename/replace/rmtree or an equivalent destructive namespace operation in ANY publication, cleanup, cancellation, fault or retry branch. Cleanup closes only definitely-owned descriptors. The sole namespace publication mutation is a single no-replace final hardlink of the owned unnamed inode; writing/chmod/fsync mutate owned inode state. No temp deletion means no stat/delete race. Absence of destructive calls protects against foreign unlink independently of other actors taking the advisory flock. No-replace is the kernel link operation, not a prior absence check.

Retain same-UID private directory/ancestor validation and bounded advisory flock. It coordinates cooperating publishers, not arbitrary same-UID actors. The protocol assumes trusted Linux kernel and genuine kernel procfs at /proc/self/fd in the process namespace; no capability/mount/credential manipulation is authorized. It does not defend process-memory tampering, kernel compromise or later owner changes to a published final. Metadata/namespace validations are sequential observations, not an atomic lease against arbitrary owner mutation. Never label mode0400 immutable against its owner or existing writable descriptors. Never use a nonexistent os.fstatfs or infer procfs genuineness solely from a path string. State environmental assumptions and observed feasibility separately.
