# Supplied stage geometry diagnostic

`diagnose(dataset_bytes, case_id, rows, stages, *, deadline_ms=10000)` returns private frozen diagnostic records, or a content-free `GeometryError`. Interrupts and other `BaseException` instances propagate. Its input rows, source-looking IDs, stage membership, ordering and Gold are caller declarations: source binding is UNVERIFIED, eligibility NOT_CHECKED, execution NOT_ATTESTED and qualification NOT_QUALIFIED. No source, store, model or runtime is accessed. Stage relations alone do not establish a complete eligible universe, score ordering or rights.

The full contract is [declared-stage-geometry-contract.md](declared-stage-geometry-contract.md). Limits include 1 MiB dataset, 512 rows, 8192 fragments, 65536 block-ID characters, 512 global Gold occurrences, 256 cases, ten stages and 5120 stage indices; returned stages contain at most 60. Exact tuples and scalar types are required. A single original deadline covers admission and all thirteen lower calls. The initial admission has a separate 3D precharge. With D bytes, F fragments, L block characters, N rows, G Gold occurrences, C cases, I indices and J=max(1,(F+1).bit_length()), the ledger requires W=42D+29(F+G+1)(J+6)+64(N+I+C+G+1) <= 67108864 and B=56D+29(4L+96F+256N+128G)+4194304 <= 134217728. These measure declared logical work and serialization allowances, not CPU instructions, peak memory, actual source IO or operating-system closure. The 13 lower calls perform 16 interval passes and own completion uses 13 passes; the coefficient is 29. At simultaneous component maxima W=49498756 and B=99024896, so the ledger caps cannot be reached with admitted component bounds. Per-digest checks are not aggregate allocation limits. The lower per-call work ceiling also applies. Returned @60 completion reuses full returned-stage completion; @20 uses its own pass.

Stage outputs include a scalar row count and opaque fingerprints; supplied ordinal tuples and raw row geometry remain local to the invocation. Fingerprints retain ordered identity. Full-stage requirement and alternative coverage is distinct from ordered @20/@60 coverage. Removal transitions record lost alternatives and requirements; cross-engine comparison is not a removal. Declared required source recall uses all mandatory chosen Gold revisions as denominator and requires every atom of a revision, independently of requirement coverage. It is undefined for no Gold or OR alternatives. Chunk MRR and nDCG are unavailable because no explicit chunk relevance mapping exists; alternative grades cannot supply one. A separate explicit graded-item rank library exists and is not called here.

The final Root-authorized bounded pure-unit run passed 45 cases, and the final Ruff check passed. Earlier runs passed 20 cases before later changes; the second Ruff check found E742, which was corrected before the final check. Unit-only resource guards are not source or runtime qualification. The final implementation remains subject to Root review. This component does not close original 009 criterion 3: future work needs an owned source catalog and eligible universe, query/RRF and same-pin verification, finite actual source cost, normal CI, typed methodology and current rights, Gold eligibility, human held-out evaluation and independent audit before MVP qualification. Supplied geometry cannot establish source truth or meaningful real-world quality.
