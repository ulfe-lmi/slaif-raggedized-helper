# Isolated GPU text embedding bridge

`predict(prepared, tokenizer_runtime)` returns a frozen `PlannedContract`: canonical execution bytes and fingerprint, detached native runtime bytes, space and definition identifiers, and the intended GPU/FP16 execution fingerprint. It revalidates prepared inputs without starting a model or worker. `validate_record(execution_record, native_runtime_record)` validates declarations only; it cannot establish live ownership or current authorization. The execution record is limited to 32768 bytes and the detached native record to 131072 bytes.

`GPUTextEmbeddingSession(worker, tokenizer_runtime)` borrows an actual live parent, its prepared launch and caller reservation. The session owns its independent native tokenizer worker and private artifact. Inference dispatch uses the guarded class methods on the retained owners, so instance-level method shadows cannot supply IDs or vectors. `encode(texts)` returns a frozen `EncodedBatch` containing immutable normalized FP32 vectors, ordered native receipts, and both identity records. It accepts bounded raw strings without prefixing, truncation, padding or GPU-side retokenization. `close()` drains only the native owner; the caller retains responsibility for its parent and reservation. Pending cleanup must be explicitly drained through the retained owner. The caller must establish current content rights before providing text.

The intended execution fingerprint describes the declared GPU/FP16 definition. The full record binds the software composition and does not certify actual precision, model quality, hardware, runtime compatibility, security, license, authorization or durable completion. Real model and GPU qualification remain separate work.
