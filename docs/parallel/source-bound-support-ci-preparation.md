# Portable source-bound support fixture

`make_owned_support` is a test helper for a later selective adapter composition, not an application API. It borrows two stores to its caller, who must close them; the pytest fixture attempts to close both even on failure. It uses the existing synthetic source and native-tokenizer helpers, which build originals, ingestion bundles, supplied unit vectors and a snapshot. No model forward or encoder is part of this fixture. Its synthetic question and labels are declarations; the original source blocks and Gold geometry are read from stored bundles. The source helper's literal text is ASCII Unicode, so this fixture does not establish non-ASCII indexing behavior.

The two chosen-case requirements cover different source revisions. The supplied first ranking row covers one of them, so support at both 20 and 60 is 1/2; both rows cover 2/2. A second case supplies an additional Gold atom, making the whole-dataset count three occurrences and three distinct atoms. Empty ranking is zero support with a nonzero denominator. Refusals include a denied source, absent case, absent Gold bundle and a wrong unrelated Gold hash; the original dataset is used again afterwards.

The binding validates source integrity at call time and checks supplied ranking scope. It does not attest query execution, ranking provenance, Gold eligibility or current rights. The diagnostic measures declared span geometry, not qualified Recall, MRR or nDCG. The synthetic vectors, query and grants do not establish model quality or real authorization. The actual raw hybrid/scorer adapter join, normal CI execution, held-out evaluation, independent audit and MVP gates remain open. This note is not an executed proof or CI result.
