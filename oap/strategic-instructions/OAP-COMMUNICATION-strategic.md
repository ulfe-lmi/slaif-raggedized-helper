# Strategic communication protocol — profile 1.0

Fixed repository and strategic roots are in AGENTS.md. No substitute FIFO/project paths.
Inspect types/owner/mode and current runtime pane bindings before operational use.

## Activation

Scaffold handoff is INACTIVE: no active/order/report/control signal. Later explicit human
activation starts the standing delegated development loop; keep that authorization reference.
Reconcile remote main, branches/PRs/checks/reviews/merge automation, active transcript, sources,
dependency/qualification gates and unrelated coding state. Select one provenance-backed draft,
expand all live fields and DHA declaration. `publish_order.py --dry-run` validates without
writes; actual publication requires runtime activation enabled and authority reference, final
order, exact expected prior active and verified remote transition. Flags do not create authority.

Publish immutable order then active with one LF under lock. Re-read; signal control OK only
after shared state exists. Use `signal-wait-response-and-wake.sh`; it owns the sole response
reader and wakes this strategic pane after validated response. Coding's sole external waiter
consumes control then supplies the small startup prompt; do not request a second FIFO read.
Fresh coding context each new round; preserve actual human-selected model/client settings.

## Review and resolve

Response OK only says a published report is ready, possibly FAILED/PARTIAL/BLOCKED. Verify
report-only SELF commit, first parent implementation, remote unique PR, exact report bytes,
scope, relevant test/docs/architecture/security/license/DHA proof and current-head required CI.
No future-CI claims in reports. Record strategic review in oap/reviews, not editing report.
Continue same objective via next suffix, wait/recheck CI, merge with expected-head guard after
all gates, or deliberately abandon with dependency reassessment. Never advance unresolved
numbers. Store resolution JSON plus authoritative timestamps in timing ledger; verify actual
default-branch outcome. Human release authority remains separate.

## Recovery and intervention

Use check_state and oap/RECOVERY.md. Read-only inspection comes before restarting processes.
Report published/lost response: inspect remote and review without resignal/reimplementation.
Consumed control/no report: explicit same-round recovery after proving old worker stopped.
Identical interrupted publication: finish only unresolved transition. Conflict: preserve and
reconcile. A stopped human session is not permission to resurrect it. Audit/helper tests use
temporary pipes and terminals, never real control.fifo/response.fifo.

Tmux recovery is exceptional: confirm pane/cwd, capture small relevant tail, find failure,
send one bounded recovery/startup instruction or restart only the owned client when justified.
Do not reset Git, change provider/profile, paste secret-bearing logs or send controls elsewhere.
No idle model polling. No sub-agent is part of the normal two-role loop.
